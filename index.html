Sound Guide

Deep drone
Air temperature. Continuous. Rising or falling produces a gentle bend.
Bird calls
Only live meat probes sing. Distinct voices. Ending rises if climbing, falls if dropping.
Done alarm
When a probe reaches its target, that bird switches to rapid continuous calling and the line turns green with DONE.
Display format
Air shows current → setpoint. Meat shows current → target (total heat).
Test Mode
Uses built-in sample data. No Home Assistant required. Accelerated plays faster.
Set individual meat targets in Settings (0 disables the alarm). Only probes that are reporting appear on the main screen.
