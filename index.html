Sound Guide

Liveness bongo
One short group of four or five soft hits, about once a minute. Means only that the program is still running. Not a bird, not temperature.
Deep drone
Air temperature. Continuous low note plus a quiet octave. Darker when the pit is low. Three brief breaks in the tone mean add wood (pit falling and well below setpoint). At most every two minutes.
Bird calls
Only live meat probes sing. Distinct voices. Ending rises if climbing, falls if dropping. If a probe is pulled or disconnected, that same voice complains in a short falling burst so you can learn which bird is which.
Stage transition
A probe can have multiple stages. Each stage ends on time limit or temperature (whichever comes first). A short distinct motif marks the transition. Only the final stage uses rapid continuous calling.
Final DONE
When the last stage of a probe ends, that bird switches to rapid continuous calling and the line turns green with DONE.
Display format
Air shows current → setpoint. Meat shows current, active stage end condition, total heat, and stage number.
Test Mode
Uses built-in sample or an imported Excel series. No Home Assistant required. Accelerated plays faster. Import/Export live in Settings.
Targets in Settings currently set a single-stage end temperature (0 disables). Multi-stage engine is active; full stage editor is next. Only probes that are reporting appear on the main screen.
